Explore

  • 行走：仅在存在 腿摆/臂摆 或 walk 动作资产时可用（衣装酱 / 我的创作）。
  • 换装：通过 outfit op → outfitLines 切换服装组可见性（衣装酱有两套服装）。
  • 头部：点头 / 摇头 由 头点头 / 头转向（或 ParamAngleX/Y）驱动。
  • 脸部：微笑 / 张嘴 / 眨眼 / 惊讶 走 play（动作资产）或 face（表情）或直接 set 语义参数。
  • 在「人物创建」构建后可在角色栏看到「✨ 我的创作」。
链路：按钮 → 按角色参数面生成 JSONL（{op:set/play/face/wait}）→ @l2dp/driver StreamIngestor 逐行校验（坏行隔离）→ LayerStack + EnvironmentLayer + Evaluator 每帧参数 → @l2dp/engine L2dmPlayer 播放/形变 → WebGL2/软光栅。
